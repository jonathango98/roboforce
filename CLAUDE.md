# rf-admin

Local admin tools for RF operations.

## Committing changes

Only commit when the user explicitly asks. When asked:

1. Group changes into logical commits — use separate commits for unrelated files
2. Stage each group specifically (avoid `git add -A`)
3. Write a concise commit message for each describing what changed and why
4. Include the co-author trailer in each commit:
   ```
   Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>
   ```

Do **not** push to any remote unless the user explicitly asks.
